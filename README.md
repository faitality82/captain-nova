# Captain Nova

A 2D space trading roguelike built in Godot 4. You play Captain Nova, a broke pilot with $200, trading across a solar system of nine orbiting planets to reach $100,000. Along the way: elastic markets, combat, boss fights, wormholes, crew, and a city platformer layer on each planet.

**Status:** in development, planned for Steam Early Access.

## What's in this repo

This is the game's **source code only**: GDScript, scenes, and the Python tools used to generate sprites and audio. Art, music, and other assets are not included, so the project will not run as-is.

- About 28,000 lines of GDScript (`scripts/`, `scenes/`, `tools/`)
- 248 commits of development history in the private repo
- Python asset pipeline: `generate_sprites.py`, `generate_audio.py`, `tools/`
